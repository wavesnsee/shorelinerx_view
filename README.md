# shorelinerx_view

This project is dedicated to plot shorelinerx waterlines in parallel with optional raster data (RGB, index, mask_clouds) 
and threshold diagram.

## Installation

Install as a uv tool

`uv tool install "sx_view @ git+ssh://git@github.com/wavesnsee/shorelinerx_viex.git@main"`

## Usage
`sx_view myfile.yaml`

## yaml
To see an example of yaml parameters, see file **src/sx_view/cli/yaml/landsat_narrabeen.yaml**
